## Fuera de alcance
- Entrega real de email, DNS, webhooks/replies, proveedor de telefonía/audio y OAuth/servicios de calendario son dependencias externas descritas por la ficha; no son cambios de paridad visual por sí mismos.
- Persistencia en tiempo real/backend para prototipos localStorage requiere alcance funcional adicional; la diferencia visual puede auditarse independientemente.

## Huecos de auditoría
- Falta el cotejo visual/funcional detallado de cada pantalla con la ficha; no hay base para afirmar paridad completa solo por existencia de componentes.

## Backend
Contrastado con `merchsmith-backend/src` y los endpoints registrados. La UI de chat, comentarios, notificaciones, reuniones y gran parte de Emails tiene soporte persistido; la referencia contiene capacidades de demo sin correspondencia directa.

### Fuera de alcance (backend)
- Telefonía, audio/grabaciones/transcripciones y voicemail: integración externa y credenciales.
- Campañas de bell announcements, sistema genérico de mensajes/email simulados y aperturas/rebotes seed: no equivalen a endpoints actuales; no añadir tablas/campos/migraciones en este rol.
- OAuth/conexiones externas solo se pueden activar con las credenciales/configuración de cada proveedor; no crear credenciales ni lanzar sincronizaciones.
