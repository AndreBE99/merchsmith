For the developer: this is a clickable, front-end prototype. All data persists in the browser's localStorage (keys prefixed ms-) — there is no server. Shared data layers worth knowing: MSCAT (product catalogue), MSSTORE (store taxonomy), MSBRANDS (brand tags), MSBrief (project briefs), DPROJ (master projects), plus the shared engines product-modal.js and comments.js. See the Field Mapping Reference for how supplier API/CSV data maps to the platform model. History dates before Jul 2026 are approximate (logged retrospectively); entries are exact from here on.
