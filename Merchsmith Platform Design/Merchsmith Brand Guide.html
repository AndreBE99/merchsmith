04
Multi-colour outlined wordmark

A special display treatment of the logotype: the wordmark redrawn as bold white outlines, with each letter echoed and offset in the secondary palette. It is the single source the background patterns are built from — every pattern in this guide is an extreme close-up cropped from this artwork.

How it works

Start from the full lockup’s wordmark, expand the letterforms into open outlines, then layer offset duplicates in Spearmint, Flare, Sky, Blossom and Zest. The overlaps create depth and movement.

Where it goes

Used whole as a hero graphic, or cropped tight for the background patterns — never re-typed or recoloured outside the secondary palette.

See it as pattern
05
Pattern

The logotype, set loose. Extreme close-ups of the multi-colour outlined wordmark — letters overlapped and offset in the secondary palette — become a flowing graphic language for backgrounds, edges and packaging.

07
Iconography

A single-weight line set, drawn on a 24px grid with rounded caps and joins — matching the open, friendly stroke of the wordmark.

  • Grid 24 × 24px artboard, 2px safe padding
  • Stroke 1.7px, consistent across the set
  • Caps & joins Rounded — never mitred
  • Corners Soft radii echo the logo loop
  • Colour Ink by default; accent only to signal state
  • Fills None — the set stays line-only
