1Who you log in as — the four contexts

Merchsmith is one platform seen through four lenses. Your organisation type decides which pages exist, what data you see, and what actions you can take. Customers & suppliers live under a distributor and never see each other; the platform admin sits above everyone.

4Primary user journeys

  • Customer order: Dashboard → Projects → Store (add products) → Project View → approve visual → approve proof → approve price → confirm date → order.
  • Distributor fulfil: Dashboard → Project View → build branding → request quote/stock/date from supplier → promote stages → Ready to Order → Order.
  • Supplier: Dashboard → enquiry (stock/date/quote) → respond → receive order → upload proof → dispatch.
  • Platform admin: Admin console → directory → view distributor → ghost → (their Dashboard).

5Style alignment — proposed fixes

You're right that styles drift. Here's what I'd standardise so the whole platform feels like one product:

  • One shared chrome. Header + sidebar + footer differ across Store / Projects / Dashboard / Admin. Consolidate into a single shared header & sidebar component (like sidebar.js) used everywhere, with the identity lockup baked in.
  • One identity model. The "logged in as" lockup (customer × distributor, or Merchsmith for admin) should render identically on every page, driven by one role/identity setting — not per-page hardcoding.
  • Consistent type & colour. All pages already pull tokens.css + the colourway theme — but a few pages hardcode logos/colours (mojo vs Merchsmith, slate footer vs teal). Route everything through tokens.
  • Consistent components. Cards, drawers, status pills, buttons, toasts are restyled per page — pull these into a shared stylesheet so a button is a button everywhere.
  • One role switch (for the prototype). Today the Project View uses Customer/Distributor; Home has a 5-way switch; Admin is separate. Unify into a single demo identity switcher that drives every page.

Confirm the structure & the four contexts, then tell me which to tackle first — I'd suggest the shared chrome + identity model, as that fixes the "disconnected / multiple styles" feeling fastest.
